# 安全审查清单

所有审查必过。发现问题通常至少 🟡，可利用漏洞 🔴。

## 注入类

- SQL 注入：字符串拼接 SQL、MyBatis `${}`、ORM 原生查询拼接
- XSS：v-html 渲染未消毒内容、innerHTML、前端拼接富文本
- 命令注入：用户输入拼入 shell 命令
- 路径遍历：文件路径拼接用户输入，未归一化/校验

## 认证与授权

- 接口缺权限校验（只判登录不判权限、横向越权：用 id 直查/改他人数据）
- JWT：算法混淆、secret 硬编码、过期校验缺失

## 敏感信息

- 密钥/密码/token 硬编码或进日志、异常信息外泄堆栈
- 前端代码暴露内部接口、注释掉的凭证
- 日志打印用户 PII（手机号、身份证未脱敏）

## 输入与输出

- 无输入校验（长度、类型、范围），信任前端校验
- 反序列化不可信数据
- 文件上传未限制类型/大小/存储路径
- SSRF：服务端请求 URL 可被用户控制
- CSRF：改状态接口无防护（依赖 Cookie 会话时）
