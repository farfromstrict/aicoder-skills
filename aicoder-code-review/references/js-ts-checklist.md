# JavaScript / TypeScript 审查清单

按需逐项过，发现问题必须定位到 `文件:行号`。本清单只列 JS/TS 语言与运行时专属检查点；AI 幻觉/伪实现、项目惯例见 `ai-code-pitfalls.md`，注入/XSS/越权等见 `security-checklist.md`，Vue 组件层见 `vue-checklist.md`。Vue + TS 项目本清单与 Vue 清单同时加载，Vue 清单只管组件层。

## 异步与并发（AI 代码高发区）

- `async` 调用漏 `await`（把 Promise 当值用）、`await` 写在非 async 函数里
- `Promise.all` 与逐条 `await` 混用：本可并发却串行，或本需顺序却并发
- Promise rejection 未捕获（无 `try/catch`、无 `.catch`）；`Promise.all` 中任一失败即整体丢弃已成功的部分结果
- 竞态：快速切换/重复提交未取消旧请求或旧定时器，后发先至覆盖新结果
- `forEach`/`map` 里放 async 回调（不等待、异常逃逸出循环）
- 定时器、事件监听、订阅未在卸载/失败路径清理（非组件代码同样适用）
- 重试/轮询无终止条件或退避，失败分支静默吞掉

## 正确性与健壮性

- `==` 而非 `===`（含 `null`/`undefined` 混判、`0`/`''`/`false` 隐式转换）
- `NaN` 未用 `Number.isNaN` 判断；数值精度、超大整数、`parseInt` 缺进制
- `this` 绑定丢失：方法作为回调传递未绑定/未用箭头函数，回调里取不到实例
- 闭包捕获循环变量（`var` 循环内异步引用）、块级作用域误用
- 可选链 `?.` 掩盖本应报错的空值；`??` 与 `||` 混用（`0`/`''` 被当缺失）
- `JSON.parse` 结果未校验结构与类型直接取字段；外部输入未做类型收窄
- 浅拷贝/引用共享导致源对象被意外修改（展开运算符只解一层、函数默认参数用可变对象）
- 数组越界返回 `undefined` 未处理、`sort()` 默认按字符串比较数值、`find` 结果未判空
- `throw` 非 `Error`（字符串/对象）导致堆栈丢失、`instanceof Error` 失效

## 模块与依赖

- 循环依赖（A 引 B、B 引 A）导致运行时导出为 `undefined`
- `require` 与 `import` 混用、ESM/CJS 互操作取值漏 `.default`
- 顶层副作用（导入即发请求/改全局）在无副作用预期处引入
- 动态 `import()` 失败无兜底、路由懒加载未处理加载失败

## TypeScript 类型专项

- `any` 泛滥、`as` / 非空断言 `!` 掩盖真实类型错误；`unknown` 未收窄直接使用
- 类型与运行时不一致：接口字段标注为必有但后端可能不返回、断言后按断言类型取字段
- API 响应、配置、事件载荷未定义类型直接取用；`catch` 参数为 `unknown` 时未收窄就取 `message`
- 泛型参数未约束或形同虚设（`T` 未参与输入输出）、过度泛型化
- 类型守卫缺失：按判别字段分支后仍访问其他分支字段；联合类型未穷尽（无 `never` 收口）
- `strict` 相关：`strictNullChecks` 下空值未处理、参数隐式 `any`
- `enum` 与字符串字面量联合混用、数字 enum 反向映射误用
- 仅类型导入未用 `import type`（触发运行时导入、加剧循环依赖）

## 性能

- 循环内 `await` / 同步阻塞；链式 `map/filter/reduce` 产生多份中间大数组
- 高频事件（scroll/input/resize）未节流/防抖；热路径重复创建对象、正则、闭包
- 大对象深拷贝、大数组 `includes`/`indexOf` 线性查找未改 `Set`/`Map`

## 可维护性

- 命名与项目既有风格不一致（大小写、文件后缀、默认导出 vs 命名导出）
- 深嵌套（>3 层用卫语句/提前返回）、超长函数
- 魔法值应提为常量
